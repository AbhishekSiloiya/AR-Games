# Shape Up Pose Club assets

pavilion-v1.png is an original empty environment generated with the built-in OpenAI image tool for this project. The exact prompt is saved beside it. Architecture, ocean, foliage and distant lighting are baked into this backplate. The live camera, joint hints, shadow, target character and game UI are rendered at runtime.

The coach reuses the project's original articulated Rizzquake glTF and wool material from assets/moon/jab. Pose demonstrations deform that mesh through its actual skeleton. No new raster character or music recording was added. The existing original pose synth music and project sound samples are retained.
