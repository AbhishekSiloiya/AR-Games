# MOON — Move ON

An expressive movement arcade for all ages, led by playful original mascots. Six experiences: Slice, Goalie, Freeze, Shape Up, Jack Attack and Jab. The playroom is a curated destination, not a directory of every inherited prototype.

## Locked visual system
- Display: self-hosted Barlow Condensed 800, upright, tightly set, oversized. Body and controls: self-hosted Space Grotesk 400/600/700. Gameplay shares these faces.
- Ground: carbon; text: warm chalk; action: acid citron. Art worlds: citrus, stadium blue, club pink, kinetic lime, cosmic lavender, boxing coral. Named tokens live in src/tokens.css.
- Structure: editorial arcade masthead, asymmetric welcome with game art, a six-poster playroom, art-led game briefing, camera readiness, unobstructed game arena, score-led results.
- Game covers compose the same mascot sprites and environments used during play. Keep the live player visible in AR games.
- Controls: flat, solid, 8px corner; visible focus, large touch targets, no looping button pulse. Motion only for purposeful feedback; respect reduced motion.
- Progress: five existing stages per game. Two stars unlock the next stage. Daily challenges must use the same six-game catalogue. Keep historical sessions and old game modules.
- Preview branch only; production integration is a separate step.

## Approved playable-world direction — 26 October
User approved expressive anime arcade worlds with the live player visible, animated original characters/hosts/rivals and earned reactions. Expressive furry/knitted mascots and comedic reactions lead the assets; adult human profile options are secondary, without a teenager-led direction. the returning playroom has a compact header and quick character/nickname picker. Actual game scenery, feedback and music must improve together. Maintain readable signals and low-latency input; no extra held tool in Slice. Preview must demonstrate all six games in play. Moodi & Quack lead the sport/space worlds; Fuzzbyte leads the club/pose/juice worlds. Profile character choices are badges, not a promise of full in-game character skin swapping.
