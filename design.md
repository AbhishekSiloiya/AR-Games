# MOON — Move ON

An expressive movement arcade for young adults. Six experiences: Slice, Goalie, Freeze, Shape Up, Jack Attack and Jab. The playroom is a curated destination, not a directory of every inherited prototype.

## Locked visual system
- Display: self-hosted Barlow Condensed 800, upright, tightly set, oversized. Body and controls: self-hosted Space Grotesk 400/600/700. Gameplay shares these faces.
- Ground: carbon; text: warm chalk; action: acid citron. Art worlds: citrus, stadium blue, club pink, kinetic lime, cosmic lavender, boxing coral. Named tokens live in src/tokens.css.
- Structure: editorial arcade masthead, asymmetric welcome with game art, a six-poster playroom, art-led game briefing, camera readiness, unobstructed game arena, score-led results.
- Original illustrated key art is promotional art. Do not imply it is a screenshot or replace the live player with it.
- Controls: flat, solid, 8px corner; visible focus, large touch targets, no looping button pulse. Motion only for purposeful feedback; respect reduced motion.
- Progress: five existing stages per game. Two stars unlock the next stage. Daily challenges must use the same six-game catalogue. Keep historical sessions and old game modules.
- Preview branch only; production integration is a separate step.
