# Scenic race, pose quest and disco implementation plan

**Goal:** Replace Sprint's unsatisfying static-feeling control with a lively race, add tangible rewards to Shape Up and make Freeze's party effects visible over the camera.

**Architecture:** Reuse the authored robot Running animation through PlayCanvas rather than overwriting bones under an animation component. Keep movement-earned scores separate from ambient animation; add a forgiving jog detector and clear motion feedback. Extend the existing Shape Up phase/seat state with once-only rewards and an eight-pose journey. Freeze uses a round-owned transparent party layer over the camera, while leaving Beat's background and Freeze's audio gate unchanged.

**Visual thesis:** A moving scenic race, a collectible pose challenge and a live disco; each game has one clear objective. **Content:** current objective, immediate action feedback, progress and earned reward. **Motion:** continuous visible authored running, stars/boost checkpoints, pose-star celebration, sweeping lights and a spinning disco ball that freeze with the music.

1. Sprint (`src/games/sprint.ts`, new focused race helper/UI and tests): investigate input/animation reset, then implement a 45-second race, visible authored run loop, immediate pace response with forgiving jog recognition, stars/checkpoints and movement-earned boosts. Keep solo/team/rivals and camera inset, fresh input and no passive score. Test first movement, held/noisy input, absence, rewards once, boost and cleanup. Root verifies animated skin/time and actual captured frames, not just helper state.
2. Shape Up (`src/shapeup-rules.ts`, game/overlay and tests): award 1–3 stars per result, advance a visible eight-pose path, build a combo and milestone rewards, show a clear round medal/rank. Keep camera, lock/result/reset phases, independent seats, missing-limb guards and one-time scoring. Test reward threshold, duplicate result, combo reset and separate players.
3. Freeze (`src/games/freeze.ts`, new party layer/helper/test): camera-visible disco ball, light beams, floor edge glow and confetti. Dance animates, Freeze stops/switches cool blue, successful stillness celebrates on resuming. Keep the body/face clear and the music gate unchanged. Test dance/freeze phase, presence, solo/two-player layout and round cleanup.
4. Integrate in the source-identical temporary runtime. Run check/build, controlled-camera gameplay sequences with pause/exit/recovery and two players, standard web-game client, inspect current gameplay screenshots and console errors. Review changes, fix material findings, update progress, commit/push the same preview branch and confirm exact-SHA Vercel READY. No production merge/promotion.
